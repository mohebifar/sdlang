**2. New defects and remaining adapter-author gaps**

The following are direct contradictions introduced by the changed text or artifacts:

1. **Two definitions of checked inputs.** Under Apply, adding `.spec/applied/<hash>.json` cannot invalidate evidence. Under Currency’s project-scope definition, that file is part of the whole tree because the applied store is not excluded. An implementation following Currency can therefore stale evidence when the transaction publishes its store entries—the cycle R13.3 intended to remove. Define the exclusion once and reference it from both sections. ([SPEC, Apply](/Users/mohebifar/dev/intentlang/SPEC.md:1097); [Currency](/Users/mohebifar/dev/intentlang/SPEC.md:1389))

2. **Parent-free reconciliation still has a parent-based contract.** The new workflow explicitly includes rebase and cherry-pick, but the reconciliation section and schema still require a two-parent representation. Define the saved-record format, bind its content digests in the plan, and specify which graph/identity inputs accompany it. Merely saving conflicted state records does not explain how the existing three-way identity procedure obtains all its inputs. ([SPEC, Moves—Branch merges](/Users/mohebifar/dev/intentlang/SPEC.md:156); [Reconciling after a merge](/Users/mohebifar/dev/intentlang/SPEC.md:1110); [Merging state files](/Users/mohebifar/dev/intentlang/SPEC.md:1152); [plan schema](/Users/mohebifar/dev/intentlang/schemas/plan.schema.json:69))

3. **The new required `lib` test file breaks the documented acquire operation.** Slots must exist when a create publishes. `path` replaces only the `main` slot, leaving the new `tests` slot required. Yet the walkthrough acquires only `src/lib/auth.ts`, runs no agent and says the declaration owns exactly that file. Specify whether acquisition can leave a test slot pending, requires an existing test mapping, or uses a different output contract. ([SPEC, Kind definitions](/Users/mohebifar/dev/intentlang/SPEC.md:681); [core-kind implementations](/Users/mohebifar/dev/intentlang/SPEC.md:701); [Outputs](/Users/mohebifar/dev/intentlang/SPEC.md:1197); [Brownfield adoption](/Users/mohebifar/dev/intentlang/SPEC.md:1304); [adapter](/Users/mohebifar/dev/intentlang/examples/nextjs-adapter.int:60))
