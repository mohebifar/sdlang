# Round 1 decisions: whole-design teardown

Model: gpt-6.1-sol (gpt-6.2-sol is rejected for this ChatGPT-account login; the user
approved the substitution). Inputs: `01-teardown.codex.md`, rebuttal `01b-*.codex.md`.

| # | Codex point | Decision | Why |
| --- | --- | --- | --- |
| 1 | Per-node transactions make interface changes impossible | **Accept, refined in 1b** | A signature change and its callers cannot each pass build alone. The unit of apply becomes a *transaction*: a changed node plus every dependent whose consumed projection changed incompatibly. Propagation runs to a fixed point over old and new graphs (catches shared-type changes and deleted edges). Ordering cycles are not merged automatically; only joint changes are. |
| 2 | Disjoint writes do not compose; branch merges unverified | **Accept** | v0 applies transactions serially on a candidate tree; checks run on the full tree before state publishes. Evidence records the tree id and check-definition hash. After a branch merge, nodes whose evidence tree is not an ancestor-consistent tree are re-verified. |
| 3 | Action table is not a decision procedure | **Accept** | Plan entries become multi-dimensional (identity, lifecycle, drift, change, obligations). Drift on a node blocks its change until resolved. Address excludes kind (`module.name`), fixing the Summary/Core-model contradiction; a kind change is `replace` at the same address. Removing a `protected` node requires `detach`. |
| 4 | Plan not bound to inputs | **Accept** | `plan.json` records baseline commit, graph hash, lock hash, state digest and fingerprints of every output in scope; apply refuses on mismatch. New files only under `may_create_under`. Anything else produces an amended plan. Crash recovery detail goes to round 6. |
| 5 | Hashes miss consumed inputs (`summary`, extern source, package policy) | **Accept** | Hashes become named projections of the canonical graph. `summary` joins the public projection. `extern` records a hash of its source. Package changes are split into skills / conventions / checks / generators components. State stores, per edge, the hash of the projection consumed. |
| 6 | One reference graph does incompatible jobs | **Accept** | Every edge has a relation, declared by the kind field it comes from. A relation declares what it consumes, whether it orders, and what imports it grants. Reference cycles are legal. |
| 7 | Capability substitution promises compatibility it cannot define | **Accept** | Capabilities stay as names so nodes need not name a library, but swapping a provider is planned as `update` on every dependent, not `verify`. No compatibility promise in v0. |
| 8 | Adoption preserves stale evidence | **Accept** | Baseline (accepted bytes) and evidence (check results on a tree) are separate. `adopt` renews the baseline and marks affected evidence `stale`. `import` starts `unverified`. New status `accepted` for explicit human sign-off. |
| 9 | Milestone cannot measure its riskiest assumption | **Accept** | Each trial edit gets an independently written acceptance check the agent cannot edit, plus a control arm (same agent, plain instructions). The runner is first driven from hand-written graph JSON, before the parser. |
| 10 | Worked example violates the import-enforcement rule | **Accept, refined in 1b** | No new `libraries:` field. Allowed imports are derived from references with relation-specific grants: `mentions`/`navigates` grant nothing; `calls` grants the target's public entry points; type references grant type-only imports; `uses` and capability references grant the bound package's runtime exports. Worked example gets complete declarations. |
| 11 | Cut custom syntax, start from JSON | **Reject** (Codex conceded in 1b) | The artifact humans review is the syntax. Keep the grammar narrow and lower everything to graph JSON. |
| 12 | Demote `action` to adapter vocabulary | **Reject** (Codex conceded) | It is the one framework-independent callable contract. Refinement accepted: `action` is defined by its callable contract only, with transport left to adapters. |
| 13 | `project`/`stack`/`use`/`module` are not implementation nodes | **Accept** | They become *context declarations*: they contribute to context projections and have no state record of their own. Only managed declarations (with outputs) get state. |
| 14 | Cut selectors, contributions, symbol ownership, templates, parallel apply | **Partly defer** | Parallel apply: deferred (v0 serial). Selectors and templates: kept, defined in rounds 2–3. Contributions and symbol ownership: round 5. |
| 15 | Cut entities and migrations from core | **Defer** | Already outside the first milestone; kept in the language, runtime state is round 8. |
| 16 | Large groups for widely-called actions | **Accept as correct** | A breaking change really does touch every caller. The spec documents the expand-migrate-contract pattern for staging it. |
| 17 | Shared output owners must join transactions | **Accept** | Folded into round 5 (ownership). |
